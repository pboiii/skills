# Codex Goal Notes

Use a compact `/goal` command and point to packet files. Keep the command under 4,000 characters. Include:

- approved objective
- goal directory
- baseline capture
- milestone loop
- validation cadence
- `STATE.md` and `PROGRESS.md` update requirements
- stop/report conditions
- final fresh-evidence requirement

Codex lifecycle wording may mention `/goal pause`, `/goal resume`, and `/goal clear`.
